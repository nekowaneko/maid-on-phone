## T2-K 重點

- 追加 `ENABLED_PATH = "/api/drink/enabled"`、`STATUS_DISABLED = 403`、`DRINK_DISABLED_MESSAGE = "戒飲記錄已關閉，請到「戒飲設定」重新開啟"`、`fun drinkUiEnabled(status: Int, enabled: Boolean?): Boolean`，文字逐字照 §4.3。
- `drinkUiEnabled`：只有「status 在 200..299 且 enabled 恰為 false」才回 false，其餘（含 `null`、非 2xx、`STATUS_NOT_SET`、`STATUS_UNREACHABLE`）一律回 true。**這是整個專案唯一允許的「讀不到就顯示」降級（A67）**，不得在別處重複。
- `workerErrorMessage` 只在 `STATUS_UNAUTHORIZED` 之後加一行 `status == STATUS_DISABLED -> DRINK_DISABLED_MESSAGE`，其餘分支與順序不動。`M2HelperTest` 既有的斷言（400、500、300、199 回 `UNREACHABLE_MESSAGE`）仍須成立。
- 只追加，不改既有函式的簽名與常數。照 `Drink.kt` 既有風格。

## T2-W 重點

- `drink-view.js`：在 `window.PetDrinkView` 加 `controlsVisibility(enabled)`，**只有參數恰為 `false`** 才回 `{ mic:false, resist:false, history:false, chat:true, ma:true }`，其他任何值（`undefined`、`null`、`'false'`、`0`）都回五個全為 true。一般 script 寫法（IIFE、`var`、分號）。
- `index.html`：`window.pet` 新增 `setDrinkEnabled(on)`：用 `controlsVisibility(on)` 對 `#mic`、`#resist`、`#history` 設定 `style.display`，隱藏時順手呼叫既有的 `clearDrinkButtons()`；**不得碰 `#chat`、`#ma`**，也不得在網頁端自己寫「讀不到怎麼辦」的判斷。
- 不新增任何載入的 script，載入順序不變；既有的 id 全部保留（沿用 V59 的 `check-dom-ids.mjs`）。
