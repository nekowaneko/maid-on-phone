## 步驟建議（照順序，每步跑 `./verify.sh`）

1. `index.html`＋`manifest.webmanifest`：視訊版結構、所有 id、名稱「手機女僕」。六顆選單按鈕保留舊 id（`#log-open` 等），放進 `#more`。
2. `style.css`：先在 `:root` 定義 `--face-width: 118cqw`、`--face-aspect-h`、`--face-aspect-w`、`--danger`、`--ok`；再寫版面。**新增的色碼只准出現在 `:root`**（V55）。
3. `renderer.js`：加 `blink(fileName, closedMs)`，任何失敗都是空操作；`zOrder` 只有 `face` 時不得出錯。
4. `app.js`：移除換裝與工具列的程式；加三個事件 `companion:send`、`companion:reply-start`、`companion:reply-failed`；**不得改動 `TYPEWRITER_INTERVAL_MS`（30）與 `HOLD_MS`（3000）**。
5. `call.js`：照 §4.4。狀態文字、按鈕文字、可用性一律來自 `callView`／`CALL_TEXT`，不得寫死（A56、V52）；連線探測的任何例外都轉成 `status: null` 後走 `connectEvent`。
6. 刪除 `outfit.js`、`tryon.html`、`tryon.js`，移除所有引用。
7. `call-wiring.test.js`：照 §4.6 W-A；需要本機表情圖，缺圖就失敗並寫 BLOCKERS.md，**不得造假圖**。

## 容易踩的地方

- 輸入框可用＝「`call.js` 允許」且「`app.js` 沒在處理中」，兩份並存，回到 live 時不得強制 `disabled = false`（§6.2）。
- 連線失敗只發生在「呼叫中」；通話中的送出失敗走既有制式回覆，狀態維持通話中（A58）。
- 重撥不得清除 `companion:history`。
- `background.js` 不改；預覽框位置若與新版面略有出入，記在 CHECKLIST，不得為了對齊而改它。
