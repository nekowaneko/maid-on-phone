### 3.3 `backend/wrangler.toml`（整檔覆寫）

照抄：

```toml
# Worker B：accompany_bot（commit 54065e9）的獨立副本。部署由使用者自行執行，步驟見 docs/WORKER-SETUP.md。
# 本機開發：在 backend/ 執行 npx wrangler dev

name = "pet-maid-api"
main = "worker/index.js"
compatibility_date = "2025-01-01"

# 靜態資源以 backend/ 為根目錄提供，讓 web/ 能以相對路徑取得 config/ 與 assets/。
# 不需要上傳的檔案列在 .assetsignore。
[assets]
directory = "./"

# 環境變數。以下金鑰一律用 wrangler secret put 設定，絕對不要寫進這個檔案：
#   APP_SECRET（存取密鑰，另開一把，不要和 accompany_bot 相同）
#   LLM_API_KEY（Gemini 金鑰，另開一把）
#   LLM_RELAY_SECRET（轉送服務的密鑰，與 accompany_bot 共用同一個轉送服務）
#   FCM_SERVICE_ACCOUNT（Firebase 服務帳戶金鑰 JSON 全文）
#   FCM_DEVICE_TOKEN（手機主畫面顯示的推播代碼）
[vars]
USE_STUB = "false"
LLM_MODEL = "gemini-3.5-flash-lite"
LLM_RELAY_ORIGIN = "https://你的中繼站網址"

# 讓 wrangler 把人設與提示詞範本當成文字模組帶進 Worker。
[[rules]]
type = "Text"
globs = ["**/*.md"]
fallthrough = false

# D1 資料庫：與 accompany_bot 分開。database_id 由使用者執行
#   npx wrangler d1 create pet-maid-db
# 之後填入，建表語句見 worker/schema.sql。
[[d1_databases]]
binding = "DB"
database_name = "pet-maid-db"
database_id = "REPLACE_WITH_PET_MAID_DB_ID"
```

### 3.6 `docs/WORKER-SETUP.md`

照抄：

````markdown
# Worker B 部署（使用者操作，約 20 分鐘）

> Worker B 是 accompany_bot 的獨立副本，提供聊天網頁與送推播。代理人不代為部署。
> 指令都在 `backend/` 資料夾執行（PowerShell）。第一次會要求登入 Cloudflare，用 accompany_bot 所在的同一個帳號即可。

## 1. 確認帳號
```powershell
npx wrangler whoami
```
顯示的帳號底下若已經有 `neko-companion`，就是 accompany_bot 所在的帳號。

## 2. 建立資料庫
```powershell
npx wrangler d1 create pet-maid-db
```
把輸出的 `database_id` 填進 `backend/wrangler.toml` 的 `REPLACE_WITH_PET_MAID_DB_ID`，然後建表：
```powershell
npx wrangler d1 execute pet-maid-db --remote --file worker/schema.sql
```

## 3. 設定金鑰（每個指令會要求貼上值）
```powershell
npx wrangler secret put APP_SECRET          # 自己想一串新的存取密鑰，不要和 accompany_bot 相同
npx wrangler secret put LLM_API_KEY         # 到 https://aistudio.google.com/apikey 另開一把 Gemini 金鑰
npx wrangler secret put LLM_RELAY_SECRET    # 與 accompany_bot 相同的轉送服務密鑰
Get-Content "$HOME\Downloads\你的服務帳戶金鑰檔名.json" -Raw | npx wrangler secret put FCM_SERVICE_ACCOUNT
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" exec-out run-as com.accompany.pet cat files/push-token.txt | npx wrangler secret put FCM_DEVICE_TOKEN
```
最後一行需要手機接線（或無線偵錯）。重裝 App 或清除資料後推播代碼會變，要重新執行這一行。

## 4. 部署
```powershell
npx wrangler deploy
```
記下輸出的網址（例如 `https://pet-maid-api.xxx.workers.dev`）。

## 5. 讓 App 知道聊天網址
1. 把專案根目錄的 `worker.properties.example` 複製成 `worker.properties`
2. 填入 `chatUrl=https://pet-maid-api.xxx.workers.dev/web/index.html`（必須是 https）
3. 重新建置並安裝 App

## 6. 測試送推播（M1.5 貴批次完成後才有這個功能）
```powershell
Invoke-RestMethod -Method Post -Uri "https://pet-maid-api.xxx.workers.dev/api/push" `
  -Headers @{ "x-app-secret" = "你的存取密鑰" } -ContentType "application/json; charset=utf-8" `
  -Body ([Text.Encoding]::UTF8.GetBytes('{"text":"該喝水了"}'))
```
成功時回覆 `ok: True` 與這則的編號，手機依角色模式與遊戲狀態出現角色、一般通知或排隊。
````
