## 不收的項目
- 點擊次數、字數上限、看起來順不順：已由使用者在原型階段目測確認。
- 比喻好不好懂：已由使用者在原型階段確認；說明文字內容由 `ma-glossary.json` 規格範例列（M4-S17）檢查必要欄位。
- 暖石板琥珀專屬規則（每頁主按鈕數、卡片數、進度條屬性）：這個產品不使用暖石板琥珀，不適用。

# 追加（2026-10-11）：聊天頁視訊版 UI 驗收項

範圍：`backend/web/index.html` 的 V1～V7。風格沿用聊天頁現況，不是暖石板琥珀。

| 編號 | 項目 | 判定方式 |
|---|---|---|
| U22 | 375px 與 1280px 寬度下，聊天頁沒有水平捲軸 | `document.documentElement.scrollWidth <= clientWidth` |
| U23 | V2 對話框下緣與角色圖上緣的垂直距離（下緣減上緣）介於 0～30px，兩者水平方向有重疊 | 瀏覽器自動測試量 `getBoundingClientRect` |
| U24 | 對話框高度固定：送出很長與很短的台詞，演出前後高度相同 | 同上 |
| U25 | V1、V4、V5 時對話框不可見且內容為空 | 計算樣式 `opacity` 為 0 或 `hidden`，且文字為空 |
| U26 | 頂列狀態文字：V1「呼叫中…」、V2「通話中 mm:ss」、V3「她在想… mm:ss」、V4「連線失敗」、V5「已結束」 | 文字比對 |
| U27 | 聊天頁名稱為「手機女僕」：頁面 `<title>`、`apple-mobile-web-app-title`、`manifest.webmanifest` 的 `name` 與 `short_name`、頂列名字 | grep 與 DOM 檢查 |
| U28 | 掛斷鈕 `aria-label` 為「掛斷」，「⋯」為「更多」，輸入框為「想說的話」 | DOM 檢查 |
| U29 | 輸入框與送出在 V1、V3、V4、V5 為停用，V2 可用 | DOM 檢查 |
| U30 | 「⋯」選單恰有 6 項（對話紀錄、小檔案、用量、上傳背景圖、更換背景圖、制式回覆），沒有「更換服裝」 | DOM 檢查 |
| U31 | 表情標籤對應：`neutral`、`laugh` → idle，其餘五個各對應自己的圖；不認得的標籤 → idle | 單元測試 |
| U32 | 演出節奏沿用聊天頁現況：每字 30 毫秒（`TYPEWRITER_INTERVAL_MS`）、逐字結束後表情保持 3000 毫秒（`HOLD_MS`）才回平常的臉；眨眼間隔 3000～5500 毫秒、閉眼 140 毫秒（2026-10-11 使用者確認 M42-S03、S05，更正原寫的 80／500 毫秒） | 單元測試（假計時器） |
| U33 | 新增或修改的樣式不含十六進位色碼；色碼只允許寫在 `style.css` 的 `:root` 變數 | grep |
| U34 | 自動化無障礙檢查（axe）對 V1～V6 新增與修改的元件沒有對比度錯誤 | axe 掃描 |
| U35 | 原型中的每個畫面（V1～V7）在實作中都有對應的狀態或抽屜 | 逐項對照 screens.md |

## 不收的項目
- 角色圖放大 118% 後看起來夠不夠清楚：來源只有 300×349，已知偏軟，由使用者在手機實測判斷，不進自動驗收。
- 距離、字級、對話框看起來順不順：已在原型階段由使用者目測確認。
