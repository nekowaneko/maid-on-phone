# F3 UI 驗收項（機械可判定，迴圈中凍結，執行端不得修改）

範圍：只針對 F3 新增的畫面（S4～S7 與 S1 的 F3 按鈕與摘要）。現有泡泡的粉、藍、綠按鈕對比不足是既有狀況，不在這次驗收內。

| 編號 | 項目 | 判定方式 |
|---|---|---|
| U1 | 375px 與 1280px 寬度下，`ma.html` 沒有水平捲軸 | `document.documentElement.scrollWidth <= clientWidth` |
| U2 | 原型中的每個畫面（S1～S7）在實作中都有對應的 Activity、通知、泡泡狀態或網頁畫面 | 逐項對照 screens.md |
| U3 | 自動化無障礙檢查（axe）對 `ma.html` 的 S4～S7 沒有對比度錯誤 | axe 掃描 |
| U4 | S5 矩陣每一格都有文字（多、空、弱、強、糾、資或「—」），不只靠顏色 | DOM 檢查 |
| U5 | S5 每個矩陣格子有 `aria-label`，內容含標的、日期、排列名稱 | DOM 檢查 |
| U6 | S4 每檔的均線順序有文字替代（由高到低的 5 日、20 日、60 日數值） | DOM 檢查 |
| U7 | 免責聲明「僅供參考，非投資建議。」出現在 S4、S5、S7 頁尾 | 文字比對 |
| U8 | S6 輸入框有 `aria-label`，錯誤文字區為 `role="alert"` | DOM 檢查 |
| U9 | S6 的查無、重複、滿 10 檔、停止追蹤、復原五種情況都能觸發，且各自顯示 screens.md 寫的文字 | 見 screens.md 規格範例表 |
| U10 | 泡泡常駐按鈕列有「📈 盤前均線」，共 5 顆 | DOM 檢查 |
| U11 | F3 新增的原始碼不含十六進位色碼（色碼集中於 `ma.css` 與資源檔） | grep |
| U12 | S4 每張卡片的「什麼意思？」按鈕有 `aria-expanded` 與 `aria-controls`，展開後內容區的 `id` 與之相符 | DOM 檢查 |
| U13 | S4 展開說明與 S7 的示意圖有 `role="img"` 與 `aria-label`，且文字含「不是實際股價」 | DOM 檢查 |
| U14 | S4、S5 有「看懂排列」入口，S7 有「返回」並回到 S4 | DOM 檢查 |
| U15 | S7 依序出現「三條線怎麼想」「轉弱與轉強」，之後恰好 8 張排列卡片 | DOM 檢查 |
| U16 | 單檔取得失敗的卡片：標籤「沒拿到」、描述「這檔資料沒拿到。」，沒有「什麼意思？」 | DOM 檢查 |

## 不收的項目
- 點擊次數、字數上限、看起來順不順：已由使用者在原型階段目測確認。
- 比喻好不好懂：已由使用者在原型階段確認；說明文字內容由 `ma-glossary.json` 規格範例列（M4-S17）檢查必要欄位。
- 暖石板琥珀專屬規則（每頁主按鈕數、卡片數、進度條屬性）：這個產品不使用暖石板琥珀，不適用。
